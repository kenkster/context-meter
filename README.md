# context-meter

Shows how full the context window is, plus plan usage (5-hour and weekly limits), in a line above the message box. Shows a one-time warning at 50%, 75% and 90% full, suggesting a handoff summary and a new chat once a conversation gets heavy.

## Install

At the prompt of a terminal session:

```
/plugin install context-meter --marketplace kenkster/context-meter
```

From a shell:

```
claude plugin install context-meter --marketplace kenkster/context-meter
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `kenkster/context-meter`, then Add plugin.
